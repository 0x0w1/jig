# Project Resources

Repository images are separated by purpose so published README assets do not get mixed with design exploration.

## README assets

`readme/` contains only files referenced by `README.md` and `README.ko.md`. These files use stable names so a visual refresh does not require a new public path.

- `readme/jig-logo.png`
- `readme/quick-start.svg`

## Branding candidates

`branding/candidates/` contains unpublished alternatives grouped by format:

- `branding/candidates/logos/`: logo and icon explorations
- `branding/candidates/heroes/`: hero image explorations

A selected candidate should replace the corresponding stable file under `readme/`; it should not remain as a duplicate in both locations. Rejected candidates can be deleted without affecting README rendering.
